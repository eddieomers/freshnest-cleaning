
# FreshNest Cleaning

A responsive website concept for a fictional
residential cleaning business.

## Project Overview

I designed and developed this website to
demonstrate how a cleaning company can
present its services and make it easier
for visitors to request a quote.

## Features

- Responsive desktop and mobile layout
- Modern navigation and hero section
- Cleaning service cards
- Interactive quote request demo
- Form validation
- Clean, professional design

## Technologies

- HTML5
- CSS3
- JavaScript

## Business Purpose

The website is designed to help potential
customers understand the available services
and find the quote request section quickly.

## Live Demo

https://eddieomers.github.io/freshnest-cleaning/

## Disclaimer

This is a fictional portfolio project.
The quote form demonstrates browser-side
functionality and does not send inquiries.
